# 告别手动切节点：一套 OpenWrt 家庭多机场自动分流配置，开源了

> 适合发布在恩山无线、V2EX 技术节点等论坛。发布前可自行调整标题与开头。

## 先说我踩过的坑

用了好几年代理，真正烦的不是"能不能连上"，而是连上之后的事：

- 机场 A 的美国节点挂了，要手动去面板换机场 B；
- 所有美国节点都不可用，手机上切日本又麻烦又慢；
- ChatGPT 想稳定、YouTube 想省流量、GitHub 想快——需求不同，却只有一个全局开关；
- 家里手机、电视、电脑每台设备都要装客户端、各配一遍。

折腾了很久，最后我把这套东西做成了**自动化**：平时只需要决定"这个平台走哪个国家"，剩下的机场测速、同国切换、跨国兜底全部自动完成。

## 这套配置能做什么

**① 四个 Wi-Fi，各管一摊（核心亮点）**

| 网段 | 示例 Wi-Fi | 行为 |
| --- | --- | --- |
| 192.168.31.x | ap-direct | 全部直连（国内应用、游戏、排障） |
| 192.168.32.x | ap-rule | 国内直连 + 海外按平台分流（日常主力） |
| 192.168.33.x | ap-Global | 全部走代理（临时全局） |
| 192.168.34.x | ap-34x | 默认住宅出口 + 白名单直连 |

全家人不用装任何客户端，连哪个 Wi-Fi 就享受哪种网络。

**② 按平台独立选国家**

ChatGPT、Claude、Gemini、YouTube、Netflix、Telegram、GitHub、Google、Steam、PayPal 等都有独立策略组。在面板里给 ChatGPT 选"美国★"、给 YouTube 选"新加坡"，互不影响。

**③ 多机场三梯队 + 故障接力**

5 个机场分成主力 / 保底 / 优质三梯队，每梯队自动测速选最快节点；同一国家的机场全挂后，自动按顺序跨国兜底（美国→日本→新加坡→…）。机场名称只是"槽位"，把你的订阅 URL 填进去就能用。

**④ 其他开箱即用的细节**

- 国内外 DNS 分流（fake-ip + 国内走阿里/腾讯 DoH、海外走 Google/Cloudflare DoH），减少泄漏；
- 节点健康检查全自动，坏节点自动剔除；
- 自定义直连域名放在独立规则文件，改完推 GitHub 即可，不用重传主配置。

## 一次请求是怎么走的

```text
设备所在网段 → 目标平台 → 你选择的国家 → 梯队里当前最快的节点
```

你只表达意图（"ChatGPT 走美国★"），配置负责找当前可用的线路。

## 部署到底难不难

**前提：先把路由器侧的网络建好**（配置本身不负责建网）：

1. OpenWrt 里创建 4 个接口 + DHCP 网段（31/32/33/34.x）；
2. 创建并绑定对应 Wi-Fi；
3. 配置防火墙区域，确认各网段能正常上网。

**然后 4 步：**

1. 把 `configs/v8.yaml` 复制为 `v8.local.yaml`；
2. 把 5 个订阅 URL 填进槽位（配置文件里有 ◆ 标记，Ctrl+F 搜索 ◆ 依次跳转）；
3. 语法检查：`clash_meta -t -f v8.local.yaml`；
4. 上传 OpenClash 启用，按 README 的清单验收。

没有路由器？仓库里还有单机版 `client/v8.yaml`，Clash Verge Rev、Clash Party、FlClash 直接导入。

## 写在前面的话（实话实说）

- 它能**减少**人工切换，但不能创造不存在的线路：所有机场都挂了，神仙也救不了；
- 需要一点点 OpenWrt / OpenClash 基础，完全零基础建议先熟悉再上；
- 模板默认按 5 个机场设计，只有 1 个订阅的朋友用它属于杀鸡用牛刀。
